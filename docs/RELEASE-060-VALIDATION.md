## 证据边界

本轮主要针对安装、分发和 UI 兼容性。真实浏览器使用现有 rc2 测试服务；rc6 与 alpha5 本轮完成安装与组件渲染测试，不能据此声称两版已完成全套真实模型或浏览器长时验证。README 的两张图片来自真实服务，不使用模拟页面替代。

本轮没有重新进行中规模付费模型 traces 测试，未生成新的 token 或缓存命中率结论。此前 Reviewer 与硬中断测试不应被冒称为此次 npm 最终制品的全量生产认证。

DSH npm latest 在本轮核验时是 0.1.2-rc.1，尚未纳入本次三版本支持范围。未知版本保持拒绝启动/拒绝安装，而不是降低安全检查后继续运行。

0.6.0 仍处于发布准备；GitHub CI、Release 和 npm 的实际发布状态须分别核对。
